About this application

CyberLab is a small banking-style Flask app used to demonstrate web application security controls: bcrypt password storage, account lockout, per-IP throttling, CSRF tokens, a strict Content Security Policy, and role-based authorisation.

Lab mode is enabled, so deliberately vulnerable counterparts of these features are also mounted under /lab for side-by-side comparison.
