Vulnerable endpoints

Every page below is broken on purpose. They exist only because CYBERLAB_LAB_MODE=1 is set; with it unset they are not registered and return 404.

VulnerabilityVulnerableHardened
SQL injection /lab/login-sqli /login
Stored XSS /lab/profile-xss /profile
Reflected XSS /lab/search-xss /search
Broken access control /lab/admin-open /admin
Cookie exfiltration sink /lab/steal —

What the defences do to these payloads

The Content Security Policy on every response sets script-src 'self', so injected inline scripts are blocked by the browser even where the server reflects them. Open the developer console to see the CSP violation. The session cookie is HttpOnly, so a payload that reaches /lab/steal carries an empty cookie value.
